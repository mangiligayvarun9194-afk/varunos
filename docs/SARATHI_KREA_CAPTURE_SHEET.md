# Sarathi Krea Capture Sheet

This is the exact visual shopping list for the Sarathi world. Generate these in Krea first,
then animate the approved frames in Seedance 2.0 / Higgsfield. The live site already has the
scroll engine, story panel, element fields and product-proof band; these assets replace the
current placeholder still/video scene by scene.

## Cultural Spine

- Chariot frame: body as chariot, senses as horses, mind as reins, guiding intelligence as the
  charioteer. Use this for the gate and the emotional promise.
- Creation order: Akasha -> Vayu -> Agni -> Apas/Jala -> Prithvi. The scroll descends from
  subtle to solid: crown, breath, belly, heart, ground.
- Fire: Vaishvanara, the digestive fire, becomes the nutrition/fuel scene.
- Water: Apas and the ocean-churning/amrita image become readiness, recovery and HRV.
- Earth: Hanuman carrying the mountain becomes visible strength, discipline and Twin growth.

Research anchors:
- Katha Upanishad chariot allegory: https://www.tota.world/article/1281/
- Taittiriya Upanishad 2.1 sequence: https://www.ccdas.net/p/five-levels-of-consciousness
- Bhagavad Gita 15.14, Vaishvanara: https://shlokam.org/gita/gita-15-14.htm
- Rig Veda 10.9, Apah Suktam: https://www.wisdomlib.org/hinduism/book/rig-veda-english-translation/d/doc838576.html
- Hanuman / Sanjeevani mountain story: https://www.vedantu.com/stories/hanuman-saves-laxmana

## Global Krea Rules

- Use Krea 2 or Nano Banana image generation.
- Use the approved master as the image reference for every scene. Same face, same armor, same
  chest core, same halo.
- Generate 16:9 frames for desktop and 9:16 frames for mobile. Do not crop the head, halo,
  chest core or extended hand.
- No text inside the image or video. All words live in the website card.
- Keep the character original: inspired by charioteer, Nataraja rhythm, Hanuman strength and
  Krishna-like guidance, but not a literal deity depiction.
- Palette: deep obsidian black, molten gold #f5b572, teal/cyan vault glow #2ec4b6 / #4cc9f0,
  plus one active element accent.
- Negative prompt for every frame: anime, cartoon, cel shaded, videogame render, plastic skin,
  blue skin, monkey face, multiple arms, extra fingers, deformed hands, chaotic fantasy armor,
  bright daylight background, text, watermark, logo.
